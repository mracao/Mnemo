MNEMO — Interactive Noir Fiction // Neo-São Paulo 2089
A browser-based cyberpunk narrative experience built entirely in HTML/CSS/JS. You play as a memory forensics detective in a dystopian São Paulo, investigating a case of stolen identity against a corporation that harvests human consciousness.

Branching story with 3 different endings
Real-time typewriter terminal interface
Procedural ambient audio engine (Web Audio API)
Evidence board, neural integrity meter, animated minimap
No libraries, no frameworks — pure vanilla

Made in one session with Claude.
